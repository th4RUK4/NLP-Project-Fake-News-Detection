# NLP Project — Fake News Detection

An NLP-based fake news classification project using classical machine learning and deep learning.

## Models
- Logistic Regression with TF-IDF
- LSTM with tokenization and embeddings

## Dataset
The project expects the cleaned dataset at `data/processed/cleaned_news.csv` with:
- `content`: original news text
- `clean_text`: normalized text
- `label`: 0 = Fake News, 1 = Real News

Raw datasets are intentionally not committed. See `data/README.md`.

## Notebook pipeline
1. `01_data_loading.ipynb` — load and inspect data
2. `02_data_preprocessing.ipynb` — deterministic text preprocessing
3. `03_feature_engineering.ipynb` — leakage-safe train/test preparation
4. `04_logistic_regression.ipynb` — TF-IDF + Logistic Regression
5. `05_lstm_model.ipynb` — Tokenizer + Embedding + LSTM
6. `06_model_evaluation.ipynb` — compare saved model metrics

## Reproducibility
Random seeds are fixed where supported. TF-IDF/tokenizer fitting is performed only on training data to avoid test-set leakage.

## Important
Model binaries are generated by the training notebooks and are not required for understanding or reproducing the pipeline. Run the notebooks locally to create the artifacts in `models/` and `reports/`.
